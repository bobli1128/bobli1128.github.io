# 认识信息学奥赛与 CSP

## 信息学奥赛是什么？

信息学奥赛是**用计算机编程解决问题**的比赛。它和数学奥赛很像，只不过我们的「笔」是 C++ 语言，我们的「草稿纸」是电脑。

在中国，这条路线由中国计算机学会（CCF）组织，从易到难大致是：

```text
CSP-J/S（第一轮） → CSP-J/S（第二轮） → NOI 省选 → NOI → 国际奥赛 IOI
```

很多同学**小升初、初升高**时，信息学特长都是一份亮眼的成绩单；到了大学，ACM 竞赛和保研、找工作更是息息相关。

## CSP-J 和 CSP-S 分别是什么？

| | CSP-J（入门级） | CSP-S（提高级） |
| ---- | ---- | ---- |
| 适合谁 | 学完基础语法的同学 | 学完入门级算法的同学 |
| 难度 | 约等于课内数学「基础题～中档题」 | 约等于课内数学「压轴题」 |
| 考两轮 | 第一轮笔试（J1）+ 第二轮上机（J2） | 第一轮笔试（S1）+ 第二轮上机（S2） |
| 建议年级 | 四年级 ~ 初二 | 初一 ~ 初三（学有余力可提前） |

!!! info "报名条件"

    报名当年 9 月 1 日起满 **12 周岁**（含）以上的同学才能参加 CSP-J/S。
    还没到年龄的同学别着急——正好利用这段时间把语法基础打得更扎实。

## 考试形式

- **第一轮（笔试）**：2 小时，满分 100 分，全是选择题和填空题，主要考计算机基础知识、程序阅读和程序填空
- **第二轮（上机）**：4 道编程大题，每题 100 分，共 400 分，在电脑上写 C++ 程序提交评测

两轮都达标才能拿到**认证证书**，其中第二轮成绩是最重要的。

## 怎么报名？

1. 每年 **7~9 月**，在 CCF 官方的报名网站注册报名（一般由学校集体组织，也可以个人报名）
2. 9 月参加第一轮，10 月参加第二轮
3. 具体通知请关注 [CCF 官网](https://www.ccf.org.cn/) 和各省 NOI 特派员网站

## 学好信奥需要什么？

1. **会基础的数学运算**：四则运算要熟练，学提高级时初中数学（负数、幂、简单几何）会帮大忙
2. **每周固定练习时间**：建议每周 3~5 小时，宁可每天 30 分钟，不要周末突击
3. **一个错题本**：把做错的题、想不出的题记下来，隔一个月再重做一遍
4. **不怕报错**：程序报错是家常便饭，调试（找错误）的能力就是这么练出来的
