# 第 0 章 · 走进编程

欢迎来到 Bobli 信奥课堂！这一章不需要任何编程基础，我们会回答三个问题：
**信息学奥赛是什么？我该用什么工具写代码？我的第一个程序长什么样？**

## 学习目标

完成本章后，你将能够：

- [ ] 说出 CSP-J / CSP-S 是什么、考什么、什么时间考
- [ ] 在自己的电脑上安装并打开一个 C++ 开发环境（Dev-C++ 或 VS Code）
- [ ] 独立写出、编译并运行你的第一个 C++ 程序
