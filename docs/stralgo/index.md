# 第 13 章 · 字符串算法

提高级的字符串题考的是「在长文本里高效找模式」：KMP 失配数组、字符串哈希、Trie 的应用是三大件，回文的 Manacher 是压轴黑科技。

## 学习目标

- [ ] 理解 KMP「文本指针不回头」的原理，会求 next 数组并手推
- [ ] 掌握字符串哈希与双哈希防冲突，会做子串判等类问题
- [ ] 会用中心扩展求最长回文子串，理解 Manacher 的两个洞察
- [ ] 建立「按需求选工具」的直觉：KMP / 哈希 / Trie / Manacher 各司其职
