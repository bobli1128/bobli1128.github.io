# 第 10 章 · 数据结构进阶

进入提高级，数据结构从「会用」升级为「会用还得会分析复杂度」。堆、并查集、哈希表、字典树，以及树状数组/线段树这两把「区间神器」，是 CSP-S 的核心考点。

## 学习目标

- [ ] 理解堆的性质，会手写堆、会用 STL 优先队列，解决「反复取最值」类问题
- [ ] 掌握并查集的合并与查询，路径压缩必写
- [ ] 会用 `map` / `unordered_map`，理解哈希思想与冲突
- [ ] 会用数组实现 Trie，解决前缀统计类问题
- [ ] 掌握树状数组（lowbit 两方向），理解线段树的适用场景
