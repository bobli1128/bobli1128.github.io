# 第 10 章 · 数据结构进阶

进入提高级，数据结构从「会用」升级为「会用还得会分析复杂度」。堆、并查集、哈希表、字典树，以及线段树/树状数组这两把「区间神器」，是 CSP-S 的核心考点。

## 学习目标

- [ ] 理解堆的性质，手写二叉堆，解决 Top-K 与优先队列问题
- [ ] 掌握并查集的合并与查询，理解路径压缩
- [ ] 掌握哈希表的思想与冲突处理
- [ ] 会用字典树（Trie）存取字符串集合
- [ ] 掌握树状数组的单点修改 + 区间查询，了解线段树

## 课程规划（编写中）

- 二叉堆与优先队列
- 并查集
- 哈希表
- 字典树 Trie
- 树状数组
