# 第 8 章 · 动态规划入门

动态规划（DP）是信奥的分水岭：想通之前觉得玄学，想通之后满眼都是它。本章从「递推 = DP」出发，学一维 DP 的分析套路和背包问题的两个核心变种。

## 学习目标

- [ ] 会用「状态 / 转移 / 边界」三步分析 DP 问题
- [ ] 掌握一维 DP：最大子段和、不相邻选取（打家劫舍）
- [ ] 掌握 01 背包的二维与一维（倒序）写法，理解「为什么倒序」
- [ ] 掌握完全背包（正序），会做「最少硬币数」类变体
- [ ] 建立「一切在预算内选物品都是背包」的题型嗅觉
