# 第 8 章 · 动态规划入门

动态规划（DP）是信奥的分水岭：想通之前觉得玄学，想通之后满眼都是它。本章从最朴素的「递推」讲起，让你第一次体会「用旧答案算新答案」的思想。

## 学习目标

- [ ] 从斐波那契出发理解「状态」和「转移」
- [ ] 掌握一维 DP（爬楼梯、最大子段和）的分析套路
- [ ] 掌握经典背包问题（01 背包、完全背包）
- [ ] 会定义 DP 三件套：状态、转移方程、初始值

## 课程规划（编写中）

- 递推与状态设计
- 一维 DP：爬楼梯与最大子段和
- 01 背包
- 完全背包与多重背包初步

!!! tip "学习心法"

    DP 的分析口诀：**「设计状态 → 找转移 → 定边界 → 按顺序计算」**。
    每道题都把四步写在本子上，写多了自然开窍。
