# 一维动态规划

## 从爬楼梯说起：DP 到底是什么？

第 4 章我们用**递推**解决了爬楼梯：$f[i] = f[i-1] + f[i-2]$。现在给这个名字正名——**递推就是最简单的动态规划（DP）**。

DP 的本质一句话：**大问题的答案，由小问题的答案拼出来；每个小问题只算一次。**

三个关键概念（分析任何 DP 题都绕不开）：

1. **状态**：`f[i]` 表示什么？（爬楼梯：走到第 i 级的方案数）
2. **转移**：`f[i]` 怎么由之前的状态算出来？（从 i-1 跨 1 级或从 i-2 跨 2 级）
3. **边界**：最小的几个状态直接给值（`f[1]=1, f[2]=2`）

## 例题热身：最大子段和

> **题目描述**　读入 $n$ 个整数（可能为负），找一个**连续**子段，使其中所有数之和最大，输出这个最大和。
>
> **输入格式**　第一行一个整数 $n$；第二行 $n$ 个整数。
>
> **输出格式**　一个整数。
>
> **数据范围**　$1 \le n \le 10^5$，$|a_i| \le 10^4$，答案可能超 int。
>
> **样例输入 / 样例输出**
>
> ```text
> 7
> 2 -4 3 -1 5 -2 6
> ```
>
> ```text
> 11
> ```

**思路分析**　暴力枚举所有子段是 $O(n^2)$，$10^5$ 的数据会超时。DP 怎么想？

**状态**：`f[i]` = **以第 i 个数结尾**的最大子段和。

**转移**：以 i 结尾的子段只有两种可能——单独一个 `a[i]`，或者接在「以 i-1 结尾的最优子段」后面：

$$f[i] = \max(a[i],\ f[i-1] + a[i])$$

翻译成人话：**前面攒下的家底是正贡献就接上，是负资产就甩掉重新开始**。

**答案**：不是 `f[n]`（最优子段不一定以 n 结尾），而是所有 `f[i]` 的最大值。

**参考代码**

```cpp
#include <iostream>
using namespace std;

long long a[100005], f[100005];

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];

    f[1] = a[1];                       // 边界：以第 1 个数结尾只能是它自己
    long long ans = a[1];
    for (int i = 2; i <= n; i++) {
        f[i] = max(a[i], f[i-1] + a[i]);
        ans = max(ans, f[i]);          // 顺手维护全局最大
    }
    cout << ans << endl;
    return 0;
}
```

拿样例走一遍：`f = 2, -2, 3, 2, 7, 5, 11`——注意 `f[2] = -2`（-4 的负资产太大，甩不掉只能硬扛），到 `f[5] = 7` 时家底转正开始起飞，最终 `11`（子段 `3 -1 5 -2 6`）。✅

## 一题多变：不相邻的最大和

> 房间排成一排，每个房间有钱 $v_i$。**不能偷相邻的两间**，最多能偷多少钱？

**状态**：`f[i]` = 考虑前 i 间房能偷的最大金额。

**转移**：第 i 间房**偷或不偷**，二选一：

- 偷第 i 间 → 第 i-1 间必须空 → `f[i-2] + v[i]`
- 不偷 → `f[i-1]`

$$f[i] = \max(f[i-1],\ f[i-2] + v[i])$$

```cpp
f[1] = v[1];
f[2] = max(v[1], v[2]);
for (int i = 3; i <= n; i++) {
    f[i] = max(f[i-1], f[i-2] + v[i]);   // 不偷 vs 偷
}
```

和爬楼梯一模一样的转移形状！**「每一步在几种选择里取最优」——这就是决策型 DP 的通用骨架**，第 10 章树形 DP 也还是它。

## DP 与搜索的关系

把最大子段和的决策过程画出来就是一棵「接/不接」的二叉搜索树——朴素搜索是指数级，DP 之所以快，是因为**很多子问题被反复算到，DP 把每个只算一次存进表里**（回忆第 4 章记忆化 fib）。所以：

> **会画搜索树 + 会发现重复子问题 = 会 DP。**

## 动手试一试

1. 手推样例的 `f` 数组每一格，检验是否与程序输出一致
2. 最大子段和变式：同时输出取得最大和的**子段起止下标**（提示：`f[i]` 甩掉负资产时更新起点）
3. 环形版最大子段和：房间围成圈（首尾相邻），怎么做？（提示：两种情况——不跨首尾的普通版；跨越首尾的 = 总和减去「最小子段和」）
4. 思考：如果要求子段**长度至少为 2**，转移和边界要怎么改？
