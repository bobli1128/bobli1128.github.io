# 第 4 章 · 函数与递归

代码越写越长怎么办？把一段功能打包成**函数**，随用随调。而「函数自己调用自己」的**递归**，是通往搜索、分治、动态规划的大门——本章是入门篇后半段的基石。

## 学习目标

- [ ] 会定义、调用函数，理解参数传递和返回值
- [ ] 理解变量的作用域
- [ ] 会用递归解决阶乘、斐波那契、汉诺塔等经典问题
- [ ] 理解递推与递归的关系

## 课程规划（编写中）

- 函数的定义与调用
- 参数、返回值与作用域
- 递归入门：从阶乘到斐波那契
- 递推：递归的镜像

!!! tip "练习建议"

    递归是抽象思维的一道坎，看懂 ≠ 会写。每个例子都要自己动手画「递归调用图」。
