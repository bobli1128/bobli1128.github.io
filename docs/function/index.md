# 第 4 章 · 函数与递归

代码越写越长怎么办？把一段功能打包成**函数**，随用随调。而「函数自己调用自己」的**递归**，是通往搜索、分治、动态规划的大门——本章是入门篇后半段的基石。

## 学习目标

- [ ] 会定义、调用函数，理解参数传递和返回值
- [ ] 理解全局变量与局部变量的作用域
- [ ] 掌握递归三要素：出口、向出口逼近、自己调用自己
- [ ] 知道递归的重复计算问题，会用手动记忆化解决
- [ ] 会用递推（数组 + 循环）解决爬楼梯、杨辉三角等问题

!!! tip "为什么这一章重要"

    第 7 章搜索就是「在图上递归」，第 8 章动态规划就是「有记忆的递归」。
    本章宁可学慢一点，也要把每次递归在纸上画出来、想明白。
