# 第 11 章 · 树与图论

图论是 CSP-S 第二轮的必考内容：**存图 → 遍历 → 最短路 → 最小生成树 → 拓扑排序**，这条工具链能解决大半个提高级的图论题。

## 学习目标

- [ ] 掌握 vector 邻接表建图模板（无向边存两遍！）
- [ ] 会把 DFS/BFS 遍历从网格迁移到图上（连通块计数）
- [ ] 按「数据特征」选对最短路算法：Floyd / Dijkstra / SPFA，理解松弛
- [ ] 掌握 Kruskal 最小生成树（排序 + 并查集），理解贪心的正确性
- [ ] 掌握 Kahn 拓扑排序，会用「拓扑序 + DP」解决 DAG 依赖问题
