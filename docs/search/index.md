# 第 7 章 · 搜索入门

搜索 = 系统地「把所有可能性走一遍」。**深度优先（DFS）**走到底再回头，**广度优先（BFS）**像水波一样层层扩散。这一章把第 4 章的递归和第 6 章的队列都派上用场——它们是入门篇的收官之战。

## 学习目标

- [ ] 掌握 DFS 模板：做选择 → 深入 → **撤销选择**（回溯三连拍）
- [ ] 会用 DFS 写全排列、组合、子集枚举
- [ ] 理解 BFS「按距离分层」的性质，会用队列实现
- [ ] 背熟迷宫最短路模板（方向数组 + vis/dist）
- [ ] 掌握四类剪枝，学会估算搜索树规模
