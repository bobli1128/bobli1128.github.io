# 第 2 章 · 分支与循环

程序不能只会一条道走到黑。**分支**让程序学会看情况做事，**循环**让程序学会重复干活——这两样是写出一切算法的门票。

## 学习目标

完成本章后，你将能够：

- [ ] 用 `if / else if / else` 处理多条件判断，理解逻辑运算符 `&& || !`
- [ ] 熟练使用 `for`、`while` 循环，掌握累加、累乘、计数三大套路
- [ ] 会用 `break` 和 `continue` 控制循环流程
- [ ] 解决水仙花数、最大公约数等经典循环题
