# 第 6 章 · 简单数据结构

数据结构 = 数据的组织方式。同样的数据，组织得好，处理起来又快又清晰。本章学习结构体、栈、队列——CSP-J 的高频考点。

## 学习目标

- [ ] 用 `struct` 把多个相关的数据打包成一个整体
- [ ] 理解栈「后进先出」并用数组模拟它
- [ ] 理解队列「先进先出」并用数组模拟它
- [ ] 了解链表的概念

## 课程规划（编写中）

- 结构体 struct
- 栈：后进先出
- 队列：先进先出
- 链表：链起来的盒子

!!! tip "为什么用数组模拟？"

    竞赛中手写数组版栈/队列比用 STL 更稳更透明，考场不慌——先学原理，STL 随后会自然掌握。
