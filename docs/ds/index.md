# 第 6 章 · 简单数据结构

数据结构 = 数据的组织方式。同样的数据，组织得好，处理起来又快又清晰。本章学习结构体、栈、队列、链表——CSP-J 的高频考点，也是后面搜索与图论的弹药库。

## 学习目标

- [ ] 会定义结构体，掌握「结构体 + sort + 自定义比较」的排序套路
- [ ] 会用数组模拟栈和队列，理解「后进先出 / 先进先出」
- [ ] 会用栈做括号匹配，用队列做约瑟夫问题
- [ ] 会用数组模拟单链表，理解「数组赢在随机访问、链表赢在插删」
