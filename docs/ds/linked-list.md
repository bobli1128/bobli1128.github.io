# 链表

## 数组的软肋

数组是一排连续房间，好处是**随机访问快**（`a[i]` 一步到位），坏处是**插队太难**：往第 2 个位置插一个人，后面 1000 个人都要挪窝。

**链表**换一种组织方式：节点散落各处，每个节点**自带下一节点的地址**（next 指针）。要找下一个节点不靠「排在一起」，靠「手里这张纸条上的地址」。

![链表结构示意](../assets/diagrams/linked-list.svg)

| 操作 | 数组 | 链表 |
| ---- | ---- | ---- |
| 访问第 $i$ 个 | $O(1)$ 一发命中 | $O(n)$ 沿链爬过去 |
| 插入 / 删除 | $O(n)$ 挪整片 | $O(1)$ 改一个指针 |
| 额外空间 | 无 | 每个节点多存一个 next |

**数组赢在随机访问，链表赢在插删**——没有谁全面胜出，按题目需求选。

## 数组模拟链表

竞赛中不真用指针，而是**用数组下标当地址**：

```cpp
int val[100005];    // val[i]：i 号节点的数据
int nxt[100005];    // nxt[i]：i 号节点的「下一个」节点编号（相当于纸条）
```

建一条 7 → 13 → 5 的链：

```cpp
val[1] = 7;  nxt[1] = 2;   // 1 号节点存 7，下一个是 2 号
val[2] = 13; nxt[2] = 3;   // 2 号节点存 13，下一个是 3 号
val[3] = 5;  nxt[3] = 0;   // 0 表示「没有下一个」（到头了）
int head = 1;               // 头指针：链从 1 号节点开始
```

**遍历**：从 `head` 出发，一路 `i = nxt[i]` 走到 0：

```cpp
for (int i = head; i != 0; i = nxt[i]) {
    cout << val[i] << " ";
}
```

**插入**：在 1 号和 2 号之间插一个存 9 的新节点 4——只改一个指针：

```cpp
val[4] = 9;
nxt[4] = nxt[1];   // 新节点先牵住后面（顺序不能反！）
nxt[1] = 4;        // 1 号再指向新节点
```

**删除**：删 2 号节点——让前驱跳过它：

```cpp
nxt[1] = nxt[2];   // 1 号直接指向 3 号，2 号被跳过
```

被删的节点不用清理——只要从链上够不着它，它就等于不存在了。

## 例题：约瑟夫问题 II（链表版）

> **题目描述**　$n$ 个人围成一圈，编号 $1 \sim n$。从 1 号开始报数，报到 $m$ 的人出圈，下一位从 1 重新报数。重复直到只剩一人，输出**最后留下来的人的编号**。
>
> **输入格式**　一行两个整数 $n$、$m$。
>
> **输出格式**　一个整数。
>
> **数据范围**　$1 \le n \le 5000$，$1 \le m \le 1000$。
>
> **样例输入 / 样例输出**
>
> ```text
> 5 3
> ```
>
> ```text
> 4
> ```

**思路分析**　上一课队列版要「出队再入队」绕圈；链表版更直接：把圈建成 `nxt` 环（$n$ 号的 next 指回 1 号），出圈 = **让前驱跳过出圈者**（`nxt[prev] = nxt[cur]`）。用 `prev` 始终记着「cur 的前一个」，删除就是一行。

**参考代码**

```cpp
#include <iostream>
using namespace std;

int nxt[5005];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i < n; i++) nxt[i] = i + 1;   // 1→2→…→n
    nxt[n] = 1;                                    // n→1：成环

    int prev = n, cur = 1;     // prev 是 cur 的前驱；从 1 号开始报
    int alive = n;
    while (alive > 1) {
        for (int step = 1; step < m; step++) {  // cur 报 1，走 m-1 步到出圈者
            prev = cur;
            cur = nxt[cur];
        }
        nxt[prev] = nxt[cur];    // 跳过 cur：出圈！
        alive--;
        cur = nxt[prev];         // 下一位从 1 重新报（prev 仍是前驱）
    }
    cout << cur << endl;
    return 0;
}
```

拿样例验证 $n=5, m=3$：依次出圈 3、1、5、2（和队列版一致！），剩 4 号——输出 `4`。✅

**同一个约瑟夫问题，两种数据结构两种写法**——队列版擅长输出「出圈顺序」，链表版擅长高效删除。比较着记，比死记一种强得多。

## 链表家族一览（认识即可）

- **双向链表**：节点多存一个 `pre[i]`（上一个），能往回走。第 10 章会用
- **STL 的 list**：现成双向链表（`#include <list>`），功能全但竞赛中数组模拟更常见
- **静态链表思想**：本课的「数组当下标当地址」——第 11 章图的邻接表建法就是它的大规模应用，**必须真正掌握**
