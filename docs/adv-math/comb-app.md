# 组合数学进阶

## 承上启下

组合数取模的计算（阶乘 + 逆元）上一课已解决。本课补三件「数数的功夫」：**恒等式**（变形化简）、**容斥原理**（重复计数修正）、**卡特兰数**（CSP-S 出场率最高的神秘数列）。

## 组合数恒等式速查

| 恒等式 | 组合意义 |
| ---- | ---- |
| $C_n^m = C_n^{n-m}$ | 选 m 个 ≡ 留下 n−m 个 |
| $C_n^m = C_{n-1}^{m-1} + C_{n-1}^m$ | 含/不含第 n 号（杨辉三角） |
| $\sum_{m=0}^{n} C_n^m = 2^n$ | 每个元素选/不选，全部子集数 |
| $C_n^0 + C_n^2 + \cdots = C_n^1 + C_n^3 + \cdots = 2^{n-1}$ | 奇偶子集各一半 |
| $C_{n+m}^k = \sum_i C_n^i C_m^{k-i}$ | Vandermonde：两堆各选凑 k 个 |

笔试「化简组合式」基本靠前三条；第二遍读题想不通时，**给每个式子讲一遍「选东西的故事」**——组合意义是化简的钥匙。

## 容斥原理：先都算上，再把重复减掉

问 1~100 中能被 2 **或** 3 整除的有几个？直接 $50 + 33 = 83$？错——**6 的倍数被算了两次**：

$$|A \cup B| = |A| + |B| - |A \cap B|$$

三个集合同样套路：加三个、减三个两两交、加回一个三集交。$n$ 个集合的通用公式（符号交替 $(-1)^{k+1}$）就是**容斥原理**。

### 例题：能被整除的数

> **题目描述**　求 1~$n$ 中能被 $m$ 个给定质数 $p_1 \ldots p_m$ 中**至少一个**整除的数的个数。
>
> **输入格式**　第一行 $n, m$；第二行 $m$ 个质数。
>
> **输出格式**　一个整数。
>
> **数据范围**　$1 \le n \le 10^9$，$1 \le m \le 15$，$p_i$ 互不相同。
>
> **样例输入 / 样例输出**
>
> ```text
> 100 2
> 2 3
> ```
>
> ```text
> 67
> ```

**思路分析**　先验算样例：能被 2 整除 $\lfloor 100/2 \rfloor = 50$ 个，能被 3 整除 $\lfloor 100/3 \rfloor = 33$ 个，同时被 6 整除 $\lfloor 100/6 \rfloor = 16$ 个被算重了——$50 + 33 - 16 = 67$ ✅。$m \le 15$ 提示用**二进制枚举子集**：$2^{15} = 32768$ 个子集，每个子集算所有质数之积的倍数个数，按子集大小奇加偶减。

**参考代码**

```cpp
#include <iostream>
using namespace std;

int p[20];

int main() {
    long long n;
    int m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) cin >> p[i];

    long long ans = 0;
    for (int mask = 1; mask < (1 << m); mask++) {   // 枚举非空子集
        long long prod = 1;
        int bits = 0;
        for (int i = 0; i < m; i++) {
            if (mask & (1 << i)) {
                prod *= p[i];              // 注意乘积可能超 long long 的题需剪枝
                bits++;
            }
        }
        long long cnt = n / prod;
        ans += (bits % 2 == 1) ? cnt : -cnt;   // 奇加偶减
    }
    cout << ans << endl;
    return 0;
}
```

这就是容斥计数的标准套路：**「容斥 + 二进制枚举子集」**，模板与具体题号解耦，洛谷搜「能被整除的数」可找到原题提交验证。

## 卡特兰数：出栈序列的秘密

$1, 1, 2, 5, 14, 42, 132, \ldots$ —— **卡特兰数** $Cat_n$。CSP-S 的高频数列，四个一模一样的马甲：

1. $n$ 个元素**依次进栈**，合法出栈序列数
2. $n$ 对括号的合法匹配数
3. $n$ 个节点的二叉树形态数
4. 网格中不穿过对角线的路径数

**递推公式**（就是「枚举与根配对」的区间 DP 味）：

$$Cat_n = \sum_{i=0}^{n-1} Cat_i \times Cat_{n-1-i} = \frac{C_{2n}^{n}}{n+1}$$

例题（自构造自洽）：读入 $n \le 19$，输出合法出栈序列数。$n=3$ → 5（枚举：123/132/213/231/321 ✓），$n=4$ → 14。

```cpp
#include <iostream>
using namespace std;

long long cat[25];

int main() {
    int n;
    cin >> n;
    cat[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = 0; j < i; j++)
            cat[i] += cat[j] * cat[i-1-j];   // 左子树 j 个 × 右子树 i-1-j 个
    cout << cat[n] << endl;
    return 0;
}
```

识别信号：「进出栈/括号/二叉树形态/不越对角线」→ 卡特兰。洛谷 [P1044 栈](https://www.luogu.com.cn/problem/P1044)（NOIP2003 提高 T3）就是它。
