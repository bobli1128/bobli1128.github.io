# 第 15 章 · 竞赛数学进阶

数论是提高级笔试和上机的常客：快速幂、筛法、扩展欧几里得、逆元、组合数，还有入门博弈论。

## 学习目标

- [ ] 掌握快速幂与取模四则铁律（除法要用逆元！）
- [ ] 会写线性筛，会用最小质因数表 O(log n) 分解质因数
- [ ] 掌握 exgcd 与费马小定理两条逆元路径及选型
- [ ] 会用「阶乘 + 逆元」求组合数取模，掌握容斥与二进制枚举子集
- [ ] 理解必败/必胜态判定，会套 NIM 定理与状态博弈 DP
