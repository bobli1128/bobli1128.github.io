# 第 3 章 · 数组与字符串

一个变量只能装一个数，可考试要处理全班 50 个同学的分数怎么办？**数组**一次开一排「房间」。字符串则是字符的数组，是阅读理解类题目的主角。

## 学习目标

- [ ] 定义、读入、遍历一维数组和二维数组
- [ ] 用数组实现计数（桶）、标记（打表）两大套路
- [ ] 掌握冒泡排序、选择排序
- [ ] 用 `string` 类型处理字符串的常见操作

## 课程规划（编写中）

- 一维数组与桶计数
- 二维数组
- 排序：冒泡与选择
- string 字符串入门
