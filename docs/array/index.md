# 第 3 章 · 数组与字符串

一个变量只能装一个数，可考试要处理全班 50 个同学的分数怎么办？**数组**一次开一排「房间」。字符串则是字符的数组，是阅读理解类题目的主角。

## 学习目标

- [ ] 定义、读入、遍历一维数组，会避开「数组越界」大坑
- [ ] 掌握**桶计数**和**标记**两大套路
- [ ] 会手写冒泡排序、选择排序，考场会用 `sort()`
- [ ] 会用二维数组表示矩阵和棋盘地图
- [ ] 掌握 `string` 的常用操作，会做回文判断等经典题
