# 第 1 章 · C++ 语法基础

从这一章开始，我们正式学习 C++ 语言本身。**变量、输入输出、运算符**是所有程序的积木——就像学语文要先学字词，学信奥要先过这一关。

## 学习目标

完成本章后，你将能够：

- [ ] 用不同的数据类型（整型、实型、字符型、布尔型）定义变量
- [ ] 用 `cin` 读入数据、用 `cout` 按题目要求的格式输出
- [ ] 熟练使用算术运算符，理解整除和取余在竞赛中的特殊地位
- [ ] 独立做出「A+B 问题」等洛谷入门题
