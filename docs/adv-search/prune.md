# 剪枝进阶

## 从「会用剪枝」到「会设计剪枝」

第 7 章认识了四类剪枝。进阶篇换个视角：**面对一道全新的搜索题，怎么系统地找出剪枝点？**四个追问：

1. **可行性**：当前部分解还可能扩展成完整解吗？（资源用光/超过目标 → return）
2. **最优性**：当前代价已不优于已知最优解吗？（求最小值时部分和 ≥ ans → return）
3. **等效冗余**：两条分支效果完全相同吗？（同层放同值的物品只试一次）
4. **顺序优化**：把「更可能成功」的分支放前面，最优解早点出现，剪枝刀更早见效

外加一条性价比之王：**上下界剪枝**——用数学算出「这条分支最好能到多少」，比逐个试快得多。

## 例题：拼等长木棍

> **题目描述**　$n$ 根小木棍，长度为 $a_i$，**不能折断**。要把它们恰好拼成 $k$ 根长度相同的大棍子（每根小棍必须用上）。若可行，输出每根大棍的长度（取最小可能）；不可行输出 `-1`。
>
> **输入格式**　第一行 $n, k$；第二行 $n$ 个整数。
>
> **输出格式**　一个整数或 `-1`。
>
> **数据范围**　$1 \le n \le 16$，$1 \le a_i \le 50$。
>
> **样例输入 / 样例输出**
>
> ```text
> 5 2
> 4 3 2 3 4
> ```
>
> ```text
> 8
> ```

**思路分析**　先定候选长度 $L$：必须整除总和（$L = sum/k$ 时才可能恰好用完；长度可以更大但「最小可能」必是整除值），且 $\ge \max a_i$。对每个候选 $L$ 做搜索：逐根大棍往里放小棍，放不下就回溯。n=16 的搜索树本来是阶乘级，靠四把剪刀活下来：

- **可行性**：剩余长度不够放当前棍 → 剪
- **顺序优化**：小棍**从大到小**排（大的选择余地小，先放它，失败早暴露）
- **等效冗余**：同长度的小棍，同一位置失败过就不再试第二根同长的
- **关键剪枝**：某根大棍的**第一个**小棍若失败（放什么都不行），整支搜素直接判负——空棍子放不下任何棍，问题出在别处

**参考代码**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[20];
bool used[20];
int n, k, L;               // L = 目标每根长度

// 第 root 根大棍、已放 len；从 idx 号小棍开始试
bool dfs(int root, int len, int idx) {
    if (len == L) return dfs(root + 1, 0, 0);   // 这根满了，开下一根
    if (root == k) return true;                  // k 根全部拼完!

    int fail = -1;                               // 等效冗余：记录失败过的长度
    for (int i = idx; i < n; i++) {
        if (used[i] || a[i] == fail) continue;
        if (len + a[i] > L) continue;            // 可行性剪枝
        used[i] = true;
        if (dfs(root, len + a[i], i + 1)) return true;
        used[i] = false;
        fail = a[i];
        if (len == 0) return false;              // 空棍放不下它 → 此 L 无解
        if (len + a[i] == L) return false;       // 恰好填满仍失败 → 此 L 无解
    }
    return false;
}

int main() {
    cin >> n >> k;
    long long sum = 0;
    for (int i = 0; i < n; i++) { cin >> a[i]; sum += a[i]; }
    sort(a, a + n, greater<int>());              // 从大到小

    if (sum % k != 0) { cout << -1; return 0; }
    L = sum / k;
    if (L < a[0]) { cout << -1; return 0; }      // 最大棍都放不下

    cout << (dfs(0, 0, 0) ? L : -1) << endl;
    return 0;
}
```

验证样例：$sum = 16$，$k = 2$ → $L = 8$。排序后 `4 4 3 3 2`：第一根 `4+4=8` 满；第二根 `3+3+2=8` 满 → 成功，输出 8。✅ 洛谷搜「小木棍」[P1120](https://www.luogu.com.cn/problem/P1120) 是完整版（k 未知、求最小），剪枝完全相同外加枚举 k。

## 剪枝设计的思维清单

| 追问 | 落地动作 |
| ---- | ---- |
| 范围能算吗 | 先用数学框定候选（如整除值、$\ge \max$）|
| 大的先试 | 排序！决策少的先上，失败早、回溯浅 |
| 重复了吗 | 同层同值跳过、`fail` 标记 |
| 空的不行呢 | 「第一根失败 → 整体无解」类结构性剪枝 |

**背下这道题的四个剪枝**——考场上 90% 的搜索剪枝题都能从中找到影子。

## 动手试一试

1. 删掉 `fail` 等效冗余和 `len == 0` 剪枝，拿 n=16 的随机大数据对比运行时间（体会剪枝威力）
2. 剪枝验证：为什么「恰好填满仍失败 → 返回无解」是正确的？（提示：填满后下一根从空开始，等价于空棍失败）
3. 思考：为什么候选长度只试 `sum/k` 而不用枚举更大的长度？（最小可能且必须整除——数学先算，搜索后干）
4. 挑战：P1120 小木棍完整版（k 未知，枚举每个合法 L，从 `max(a)` 开始），加上「把同样的 L 失败缓存」再提速
