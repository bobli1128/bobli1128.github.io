# 第 14 章 · 搜索与优化进阶

提高级的搜索不能只是「能跑」：要有剪枝、有顺序优化，还要会分治和倍增这两大通用思想。

## 学习目标

- [ ] 面对新搜索题能系统找出剪枝点（四个追问 + 上下界估算）
- [ ] 理解迭代加深「重复浅层不亏」的数学，会写 IDDFS + 估价函数
- [ ] 掌握归并分治框架，会用归并排序 O(n log n) 求逆序对
- [ ] 掌握 ST 表（静态区间最值 O(1)）和倍增 LCA 的思想

!!! tip "复杂度意识"

    每写一个搜索都要估算状态数：$10^8$ 是通用警戒线，超了就要考虑剪枝或换算法。
