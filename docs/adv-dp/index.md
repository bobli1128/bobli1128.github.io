# 第 12 章 · 动态规划进阶

入门篇学会「设计一个一维状态」后，本章把 DP 的状态维度和技巧全面升级：两序列、区间、树上、二进制集合——四大形态一次配齐。

## 学习目标

- [ ] 掌握 LIS（含 $O(n \log n)$ 思想）与 LCS 的状态设计
- [ ] 理解区间 DP「按长度从小到大」的填表顺序与分割点转移
- [ ] 掌握树形 DP 的 DFS 骨架与「互斥两态」设计
- [ ] 会用位运算表示集合，掌握棋盘类与 TSP 两类状压 DP
- [ ] 建立「状态形状决定 DP 类型」的题型嗅觉
