# 关于本站

**Bobli 信奥课堂** 是一套写在 GitHub Pages 上的 C++ 信息学奥赛（CSP-J / CSP-S）在线教程。

🌐 **线上地址：<https://bobli1128.github.io/>**

## 这个站是给谁的？

- **小学四年级 ~ 初三**、对编程和信息学奥赛感兴趣的同学
- 想从**零基础**开始系统学习 C++，走 CSP-J → CSP-S 路线的同学
- 带孩子入门信息学的家长和老师（课程顺序即教学顺序）

## 课程设计

- 大纲参照 **CCF 官方《NOI 系列认证大纲》**，按「入门级（CSP-J）→ 提高级（CSP-S）」两个阶段组织
- 参考了 OI Wiki、洛谷题单、《信息学奥赛一本通》等成熟教材的组织方式，再按低年级同学的认知水平重新编排
- 每一课尽量做到：生活化的比喻讲概念 → 完整可运行的代码 → 课后动手练习
- 所有例题代码均可在 Dev-C++ / VS Code 中直接编译运行，并与 CSP 真题风格接轨

## 技术栈

- 文档框架：[MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)（样式借鉴了 [hello-algo](https://www.hello-algo.com/)，在此致谢）
- 部署方式：GitHub Actions 自动构建，推送到 `master` 即自动上线
- 站点地址：<https://bobli1128.github.io/>
