# 第 9 章 · 竞赛数学基础

CSP 第一轮笔试的半壁江山，以及第二轮里的「数学味」题目，都靠本章：进制、位运算、质数、公约数和简单计数。这些内容小学奥数学过的同学会倍感亲切。

## 学习目标

- [ ] 熟练进行二、八、十六进制与十进制的互相转换，掌握存储单位换算
- [ ] 掌握 6 个位运算符和 4 个经典技巧（判奇偶、取第 k 位、`1<<k`、消最低位 1）
- [ ] 会用筛法批量求质数，掌握辗转相除与 lcm 公式（先除后乘防溢出）
- [ ] 理解算术基本定理及因数个数公式
- [ ] 掌握排列组合、杨辉三角递推，会做网格路径计数
