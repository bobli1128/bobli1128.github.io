# 第 9 章 · 竞赛数学基础

CSP 第一轮笔试的半壁江山，以及第二轮里的「数学味」题目，都靠本章：进制、位运算、质数、约数和简单计数。这些内容小学奥数学过的同学会倍感亲切。

## 学习目标

- [ ] 熟练进行二进制、八进制、十六进制与十进制的互相转换
- [ ] 掌握位运算 `& | ^ << >>` 及经典技巧
- [ ] 会判断质数、求最大公约数（辗转相除法）与最小公倍数
- [ ] 理解算术基本定理、约数个数
- [ ] 会做简单的排列组合计数

## 课程规划（编写中）

- 进制与转换
- 位运算及技巧
- 质数与筛法入门
- 最大公约数与最小公倍数
- 简单计数与排列组合

!!! tip "和笔试的关系"

    第一轮笔试中「计算机基础知识」还包括计算机发展史、存储单位（KB/MB/GB）、
    简单的逻辑运算等，会在本章「进制与转换」一课中一并梳理。
