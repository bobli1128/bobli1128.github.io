# 进制与位运算

## 计算机的母语：二进制

计算机里所有数据都是 0 和 1。这一课学**进制转换**（第一轮笔试必考）和**位运算**（竞赛代码的常用武器）。

## 进制与转换

不同进制用「逢几进一」区分：二进制逢二进一，八进制逢八进一，十六进制逢十六进一（十六进制用 A~F 表示 10~15）。

### 各种进制 → 十进制：按权展开

每一位乘以「基数的位数次幂」再相加：

$$\begin{aligned}
(1011)_2 &= 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 11 \\
(2AF)_{16} &= 2 \times 16^2 + 10 \times 16^1 + 15 \times 16^0 = 687
\end{aligned}$$

### 十进制 → 其他进制：除基取余

不断除以基数记录余数，**余数倒着读**。以 13 → 二进制为例：

```text
13 ÷ 2 = 6 余 1   ↑
 6 ÷ 2 = 3 余 1   ↑
 3 ÷ 2 = 1 余 1   ↑  从下往上读：1101
 1 ÷ 2 = 0 余 1   ↑
```

所以 $(13)_{10} = (1101)_2$。

### 二八十六进制的快捷通道

每 **3 位二进制 = 1 位八进制**、每 **4 位二进制 = 1 位十六进制**，从小数点向左每 3 位（或 4 位）一组直接替换：

```text
(1101 0110)₂ → 1101=D, 0110=6 → (D6)₁₆
```

### 常见的笔试配套知识

- 存储单位：$1\text{KB} = 1024\text{B} = 2^{10}$ 字节，1MB = $2^{20}$，1GB = $2^{30}$
- 一个字节 = 8 位（bit），能表示 $0 \sim 255$（即 $2^8$ 个值）
- $n$ 位二进制能表示 $2^n$ 个不同的值

## 位运算：直接操作二进制位

C++ 有 6 个位运算符，全部是**逐位**运算：

| 运算符 | 名称 | 规则 | 例子（按位） |
| :--: | ---- | ---- | ---- |
| `&` | 与 | 都 1 才 1 | `6 & 3` = `110 & 011` = `010` = 2 |
| `\|` | 或 | 有 1 就 1 | `6 \| 3` = `111` = 7 |
| `^` | 异或 | 不同才 1 | `6 ^ 3` = `101` = 5 |
| `~` | 取反 | 0 变 1、1 变 0 | `~5` = `...11111010`（负数） |
| `<<` | 左移 | 整体左移低位补 0 | `3 << 2` = 12 |
| `>>` | 右移 | 整体右移高位补符号 | `12 >> 2` = 3 |

两个必背结论：**`x << k` 等于 $x \times 2^k$，`x >> k` 等于 $x \div 2^k$（向下取整）**。位移比乘除法快，更重要的是 $2^k$ 有标准写法 `1 << k`。

## 四个经典技巧

**① 判断奇偶**：`n & 1` 为 1 是奇数（末位是 1）。

**② 取出第 k 位**（从 0 数）：`(n >> k) & 1`。

**③ 快速幂的雏形**——逐位处理：

```cpp
// 计算 2 的幂：检查 n 的二进制每一位
for (int k = 0; k < 10; k++) {
    if ((n >> k) & 1) cout << k << " ";
}
```

**④ 状态压缩预告**：用一排 0/1 表示「每件物品选没选」——`10110` 就是「选 1、2、4 号」。第 12 章状压 DP 全靠它。

## 例题 1：进制转换

> **题目描述**　读入一个十进制正整数 $n$ 和目标进制 $b$（$2 \le b \le 16$），输出 $n$ 的 $b$ 进制表示。
>
> **输入格式**　一行两个整数 $n$、$b$。
>
> **输出格式**　一行，$b$ 进制表示（10~15 用大写 A~E）。
>
> **数据范围**　$1 \le n \le 10^9$。
>
> **样例输入 / 样例输出**
>
> ```text
> 13 2
> ```
>
> ```text
> 1101
> ```

**思路分析**　「除基取余」的代码化：余数装进字符串，最后**倒序**输出。余数可能到 15，用 `'0' + r`（$r < 10$）或 `'A' + r - 10`（$r \ge 10$）转成字符。

**参考代码**

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    long long n;
    int b;
    cin >> n >> b;
    string s = "";
    while (n > 0) {
        int r = n % b;                 // 取余数
        if (r < 10) s += '0' + r;
        else s += 'A' + (r - 10);
        n /= b;                        // 除基
    }
    reverse(s.begin(), s.end());       // 余数倒序才是答案
    cout << s << endl;
    return 0;
}
```

注意 `reverse` 来自 `<algorithm>`——第 3 章的 `sort` 的邻居。**「除基取余 + 倒序」与「%10 拆位」是同一个思想的两种进制**，笔试年年考。

## 例题 2：二进制中 1 的个数

> **题目描述**　读入一个非负整数 $n$，输出它的二进制表示中 1 的个数。
>
> **输入格式**　一个整数 $n$。
>
> **输出格式**　一个整数。
>
> **数据范围**　$0 \le n \le 10^9$。
>
> **样例输入 / 样例输出**
>
> ```text
> 13
> ```
>
> ```text
> 3
> ```

**思路分析**　13 = `1101`，有 3 个 1。方法一：不断 `n & 1` 查末位再 `n >>= 1` 右移，循环到 0——最多 30 次。方法二（惊艳写法）：`n & (n - 1)` 每执行一次**恰好消灭最低位的 1**，数执行次数即可。

**参考代码**

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int cnt = 0;
    while (n > 0) {
        n = n & (n - 1);   // 消灭最低位的 1
        cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

为什么 `n & (n-1)` 能消灭最低位的 1？手推一次 `1100 & 1011 = 1000` 就懂：减 1 让最低位的 1 变 0、它后面的 0 全变 1，与运算一挡，正好切走。洛谷搜「二进制中 1 的个数」有同款练习。

## 动手试一试

1. 心算：$(23)_{10}$ 的二进制、$(101101)_2$ 的十进制、$(3E)_{16}$ 的十进制
2. 笔试模拟：$2^{10}$ 字节 = 1KB，那么 4GB 等于多少 MB？多少字节？
3. 用位运算写：读入 $n$ 和 $k$，输出 $n$ 的二进制第 $k$ 位（从 0 数）
4. 思考：`n >> 1` 和 `n / 2` 结果一样吗？（提示：负数时不一样——右移向下取整，除法向零取整）
