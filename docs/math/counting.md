# 简单计数与排列组合

## 计数原理：加法与乘法

一切计数的源头是两条原理：

- **加法原理**：几类办法互不重叠、任选其一能完成 → 方法数**相加**。从北京到上海，坐 3 班高铁或 2 班飞机，共 $3 + 2 = 5$ 种
- **乘法原理**：完成一件事要**分几步**，每步各自选择 → 方法数**相乘**。3 班高铁 + 到沪后 2 种地铁到家，共 $3 \times 2 = 6$ 种

**判断用加还是用乘，看「完成它」需要「或」还是「且」**——这一句话能解决笔试里一半的组合题。

## 排列：有顺序的选

从 $n$ 个不同元素中选 $m$ 个**排成一列**，方法数：

$$A_n^m = n \times (n-1) \times \cdots \times (n-m+1) = \frac{n!}{(n-m)!}$$

直觉：第 1 个位置 $n$ 种选法，第 2 个剩 $n-1$ 种……乘法原理连乘 $m$ 项。$n$ 个全排是 $A_n^n = n!$（第 4 章的全排列搜索树，叶子恰好 $n!$ 个）。

## 组合：无顺序的选

从 $n$ 个不同元素中选 $m$ 个**组成一组**（不看顺序），方法数：

$$C_n^m = \frac{A_n^m}{m!} = \frac{n!}{m!\,(n-m)!}$$

除以 $m!$ 是因为同一组元素有 $m!$ 种排法，在「组合」里全算一种。$\binom{n}{m}$ 常写作 $C_n^m$。

**记忆锚点**：「选人开会（不讲座次）用组合，排队照相（讲顺序）用排列」。

## 杨辉三角：组合数的计算器

第 4 章见过的杨辉三角，其实是组合数表——第 $n$ 行第 $m$ 个正是 $C_n^m$：

$$C_n^m = C_{n-1}^{m-1} + C_{n-1}^m$$

组合意义：「包含第 $n$ 号元素」+「不包含」两类互斥方案相加。**竞赛里组合数几乎从不用阶乘硬算**（分母除法有精度/取模难题），而是用这条递推式填表——$O(n^2)$ 无除法，稳。

## 例题 1：组合数计算

> **题目描述**　读入 $n$ 和 $m$（$0 \le m \le n \le 30$），输出 $C_n^m$。
>
> **输入格式**　一行两个整数 $n$、$m$。
>
> **输出格式**　一个整数。
>
> **数据范围**　$0 \le m \le n \le 30$。
>
> **样例输入 / 样例输出**
>
> ```text
> 30 15
> ```
>
> ```text
> 155117520
> ```

**思路分析**　杨辉三角递推填表。$C_{30}^{15}$ 高达 1.5 亿，`int`（约 21 亿）勉强够但太悬——$C_{34}^{17}$ 就爆了，**组合数一律 long long**。

**参考代码**

```cpp
#include <iostream>
using namespace std;

long long C[35][35];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i <= n; i++) {
        C[i][0] = 1;                       // 从 i 个里选 0 个：1 种
        for (int j = 1; j <= i; j++) {
            C[i][j] = C[i-1][j-1] + C[i-1][j];   // 杨辉三角递推
        }
    }
    cout << C[n][m] << endl;
    return 0;
}
```

## 例题 2：路径计数（经典中的经典）

> **题目描述**　$N \times M$ 的网格，从左上角 $(1,1)$ 走到右下角 $(N,M)$，每步只能向右或向下走一格。问有多少条不同路线。
>
> **输入格式**　一行两个整数 $N$、$M$。
>
> **输出格式**　一个整数。
>
> **数据范围**　$1 \le N, M \le 15$。
>
> **样例输入 / 样例输出**
>
> ```text
> 3 3
> ```
>
> ```text
> 6
> ```

**思路分析**　**一题两解，这正是它经典的原因**：

**解法一（DP）**：到任何格子的路线数 = 左边格子 + 上边格子的路线数之和：

$$f[i][j] = f[i-1][j] + f[i][j-1]$$

边界：第一行、第一列全为 1（一路向右/向下的唯一走法）。

**解法二（组合数）**：总共要走 $N+M-2$ 步，其中恰好 $N-1$ 步向下、$M-1$ 步向右。路线由「哪几步是向下的」唯一决定——从 $N+M-2$ 步里选 $N-1$ 步向下：

$$C_{N+M-2}^{N-1}$$

$N=M=3$ 时 $C_4^2 = 6$。两种视角殊途同归——**「网格路径 = 组合数」**是 CSP 笔试的高频考点。

**参考代码（DP 解法）**

```cpp
#include <iostream>
using namespace std;

long long f[20][20];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) f[i][1] = 1;
    for (int j = 1; j <= m; j++) f[1][j] = 1;
    for (int i = 2; i <= n; i++)
        for (int j = 2; j <= m; j++)
            f[i][j] = f[i-1][j] + f[i][j-1];
    cout << f[n][m] << endl;
    return 0;
}
```

## 计数三防（笔试防坑清单）

1. **重复**：两个方案被算两次？分类要**互斥**（不重）
2. **遗漏**：某类方案没数到？分类要**完备**（不漏）——「互斥且完备」才能用加法
3. **顺序**：题目到底讲不讲顺序？讲 → 排列 $A$；不讲 → 组合 $C$

## 动手试一试

1. 手算：5 个人选 3 人值日，多少种？5 个人排成一排照相，多少种？（答案：$C_5^3 = 10$，$A_5^5 = 120$）
2. 6 个同学互相握手，每两人握一次，共握多少次？（组合 $C_6^2 = 15$）
3. 网格有障碍版：$3 \times 3$ 网格中间 $(2,2)$ 是障碍不能走，DP 代码只需改一行——哪一行？
4. 思考：$C_n^m$ 递推表里，为什么 $C_{30}^{15}$ 用 `int` 存会出问题，而「路径计数」$N,M \le 15$ 时 `int` 恰好够？（最大 $C_{28}^{14} \approx 4 \times 10^7$）
