# 第 5 章 · 基础算法

算法 = 解决问题的步骤。本章学习竞赛中最基础、出场率最高的四个套路：**枚举、模拟、排序应用、贪心与二分**。CSP-J 第二轮的前两题，基本就是它们的组合。

## 学习目标

- [ ] 用枚举（暴力）拿下「能枚举就别客气」的题
- [ ] 按题意一步步「翻译」出模拟程序
- [ ] 会手写排序并理解排序在题目中的应用
- [ ] 理解贪心的「局部最优 → 全局最优」思想及正确性判断
- [ ] 掌握二分查找，并推广到二分答案

## 课程规划（编写中）

- 枚举：一个不漏地试
- 模拟：把题目翻译成代码
- 排序及其应用
- 贪心算法
- 二分查找与二分答案

    CSP-J 第二轮 T1/T2 真题是最好的练习材料，历年真题在 [洛谷题库](https://www.luogu.com.cn/problem/list?keyword=CSP-J) 均可提交。
