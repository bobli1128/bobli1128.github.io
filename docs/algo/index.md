# 第 5 章 · 基础算法

算法 = 解决问题的套路。本章学习竞赛中最基础、出场率最高的四个：**枚举、模拟、贪心、二分**。CSP-J 第二轮的 T1、T2，基本就是它们的组合拳。

## 学习目标

- [ ] 会枚举：对象选得准、范围不重不漏、会剪枝省时间
- [ ] 会模拟：把题面逐句翻译成代码，拿样例手动验证
- [ ] 理解贪心「局部最优 → 全局最优」，知道贪心什么时候会错
- [ ] 掌握二分查找模板，理解「答案单调可验证，就二分猜它」
- [ ] 建立**复杂度意识**：动手前先估算运算量
